# HILAAL — General Shop & Smart Commerce

A modern general shop and smart retail management system built with React, Vite, Node.js, and Express, featuring bilingual support (**Soomaali 🇸🇴 & English 🇬🇧**), real-time inventory management, local mobile money payments (EVC Plus, ZAAD, Sahal, eDahab), cash on delivery, and a complete admin workspace.

---

## 🌟 Tilmaamaha Muhiimka ah / Key Features

- 🌐 **Labo Luqadood (Bilingual)**: Taageero buuxda oo Soomaali iyo Ingiriis ah, oo hal gujin (click) lagu kala beddeli karo.
- 🛒 **Storefront Casri ah**: Dukaamaysi degdeg ah, qiimo dhimis, gaari wax iibsiga (cart), iyo raadinta dalabka (order tracking).
- 📱 **Hababka Lacag Bixinta Soomaalida**: Taageero toos ah oo loogu talagalay EVC Plus, ZAAD, Sahal, eDahab iyo Kaashka marka laguu keeno (Cash on Delivery).
- 📦 **Maamulka Bakhaarka (Inventory Management)**: Khaanadaha, xisaabaadka, iibka dukaanka (POS), alaab-qeybiyeyaasha, iyo warbixinno maaliyadeed.
- 🌓 **Dark & Light Mode**: Naqshad indhaha u roon oo mugdi iyo caddaan ah.

## 🚀 Bilowga / Getting Started

### 1. Rakibida (Installation)

```bash
# Ku shub dhammaan xirmooyinka (client & server)
npm install
```

### 2. Deegaanka (Environment Setup)

Koobiyee tusaalaha deegaanka:
```bash
cp server/.env.example server/.env
```

### 3. Daaran (Run Development Server)

```bash
npm run dev
```

Tani waxay si wadajir ah u bilaabi doontaa:
- **Client (Frontend)**: `http://localhost:5173`
- **Server (Backend API)**: `http://localhost:4000`

### 4. Dhismaha (Production Build)

```bash
npm run build
```

## 🛠️ Teknoolajiyada / Tech Stack

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Framer Motion, TanStack Query, Lucide Icons.
- **Backend**: Node.js, Express, TypeScript, MongoDB / Mongoose, JWT Auth.
